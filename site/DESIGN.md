# FlowDiff site direction

Design read: developer-tool landing page for engineers and curious builders,
using the warm editorial surface, split hero, command bar, and layered visual
rhythm observed in the Taste Skill reference. The implementation is original:
the copy is new, the hero report is FlowDiff's own synthetic artifact, and the
paper texture is generated for this project.

## Decisions

- Variance 7: asymmetric split hero, offset report frame, and uneven content columns.
- Motion 4: short entry reveals and tactile hover states; all motion collapses under reduced motion.
- Density 3: generous spacing, one primary action, and short sections.
- Palette: warm ivory, charcoal, and one burnt-orange accent.
- Type: local system sans for clarity with a restrained Georgia editorial contrast in the hero lede.
- Theme: one warm paper theme with a dark preference variant, not alternating section themes.
- Assets: local generated texture plus the real FlowDiff synthetic report. No remote fonts, tracking, or external image URLs.

## Proof-of-concept flow

1. Open the static page from the repository's `site/` directory.
2. Read the value proposition and inspect the real report artifact.
3. Copy the local demo command and follow the schema link.
4. Deploy the same folder with the GitHub Pages Actions artifact workflow.
5. Verify the published URL, default-branch SHA, and workflow environment.
